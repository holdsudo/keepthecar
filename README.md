# bestleaseend.com

One-page consumer site, published by Champion Auto Finance (disclosed in the footer).
Registrar: Namecheap (bought 2026-10-19). Hosted on GitHub Pages from `holdsudo/keepthecar`:
`.github/workflows/pages.yml` publishes `site/` on every push to `main` (custom domain in
`site/CNAME`). Deploy = commit + push. Not on the GoDaddy account.

## Files
- `site/index.html` — the whole site (inline CSS, Google Fonts, FAQ + WebPage JSON-LD)
- `site/robots.txt`, `site/sitemap.xml`

## Editorial rules (do not break)
- Never print "Lease End" as a company name. "lease end" only as the generic phrase.
  The domain's defense is that the phrase is descriptive.
- Exactly ONE link to championautofinance.com (in the "Who is worth a call" block).
  The footer disclosure names CAF but is plain text.
- Keep the footer disclosure ("published by Champion Auto Finance… not a lender").
- No lead form. No analytics unless asked.
- Big players are never named. The two named companies are deliberately small and
  non-competing; re-check they are live before any redeploy:
  - Lease Buyout Center, Irvine CA — https://leasebuyoutcenter.com/ (© 2026 seen 2026-10-19)
  - World Auto Group, Glendale CA — https://worldautoleasing.com/ (live 2026-10-19)
  Rejected as real competitors: Lease End Department, Tresl, Lease Solutions.
  Canadian mentions (Clutch, Leasebusters) are unlinked by design.
- Same public positioning rules as the main site: lease buyouts only, "not a lender",
  no refinancing / dealer-financing wording, no "we shop your deal" language.
